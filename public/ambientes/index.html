Seis ambientes.

CONQUEST é um jogo educativo 3D que une frontend em JavaScript, React e Babylon.js, autenticação em nuvem, API REST, PostgreSQL e testes automatizados. Aqui estão as ferramentas utilizadas no desenvolvimento e as evidências da atividade.

Arquitetura da aplicação

Frontend + Backend + Banco

A interface e o motor 3D são servidos pelo GitHub Pages. O Nhost hospeda os serviços de autenticação, Functions Node.js e o PostgreSQL.

FrontendGitHub Pages · Vite · React · Babylon.js
↓
BackendNhost Auth · Functions REST · GraphQL
↓
Banco persistentePostgreSQL · tabelas de partidas e ranking
